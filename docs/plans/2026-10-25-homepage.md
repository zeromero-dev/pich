# Homepage Restructure Implementation Plan (P3)

> Work through the tasks in order. Each task ends with a verify step and a commit. Tick `- [ ]` → `- [x]` as you go.

**Goal:** Homepage = Hero → Categories carousel → New Arrivals carousel → Events editorial block (no calendar/event data) → "Люди, які створюють ці роботи" artists carousel.

**Architecture:** One CSS scroll-snap `Carousel` component (native horizontal scroll, prev/next buttons on desktop, peek of the next card on mobile via fractional item widths) serves all three carousels. Category tiles come from a new `rootCategoriesOf(products)` next to `categoriesOf` in `lib/hugeprofit/index.ts` and link to `/shop?category=<id>`, which `ShopView` reads after mount. The events block reuses the existing `AboutTeaser` text-and-photo layout, renamed. All data comes from the one cached `getCatalog()` call the page already makes.

**Tech Stack:** Next.js 16 App Router (server page + client sections), Tailwind 4, `motion/react` (`m` only), lucide-react.

**Spec:** `task/TASK.md` §2, §7.1. References: `task/assets/image1.webp` (category tiles: photo + overlaid label), `image2.webp` (new-in row), `image3.webp` ("view all" button), `image4.webp` (events block: text + photo; the brief's index mislabels it as New Arrivals), `image5.webp` (duplicate of image2, overview default A11).
```tsx
'use client'

import { Children, useRef } from 'react'
import { useReducedMotion } from 'motion/react'
import { ChevronLeft, ChevronRight } from 'lucide-react'
import { useLocale } from '@/components/providers'
import { Reveal } from '@/components/reveal'
import { cn } from '@/lib/utils'

/**
 * Native scroll-snap row. Fractional `itemClassName` widths make the next card
 * peek on mobile (brief §2.2). `py-2` keeps the cards' hover lift from being
 * clipped — overflow-x:auto forces overflow-y to clip too.
 */
export function Carousel({
  title,
  action,
  itemClassName,
  children,
}: {
  title: string
  action?: React.ReactNode
  itemClassName: string
  children: React.ReactNode
}) {
  const ref = useRef<HTMLUListElement>(null)
  const reduced = useReducedMotion()
  const { t } = useLocale()

  const scroll = (direction: 1 | -1) => {
    const el = ref.current
    if (!el) return
    el.scrollBy({ left: direction * el.clientWidth * 0.8, behavior: reduced ? 'auto' : 'smooth' })
  }

  const arrow =
    'hidden h-10 w-10 items-center justify-center rounded-full border border-ink/15 text-ink transition-colors hover:bg-surface-alt md:inline-flex'

  return (
    <div>
      <Reveal className="mb-4 flex items-end justify-between gap-4">
        <h2 className="text-2xl font-semibold tracking-[-0.02em] text-ink text-balance md:text-3xl">
          {title}
        </h2>
        <div className="flex shrink-0 items-center gap-2">
          {action}
          <button type="button" onClick={() => scroll(-1)} aria-label={t.landing.prev} className={arrow}>
            <ChevronLeft className="size-5" strokeWidth={1.75} aria-hidden="true" />
          </button>
          <button type="button" onClick={() => scroll(1)} aria-label={t.landing.next} className={arrow}>
            <ChevronRight className="size-5" strokeWidth={1.75} aria-hidden="true" />
          </button>
        </div>
      </Reveal>
      <ul
        ref={ref}
        aria-label={title}
        className="-mx-4 flex snap-x snap-mandatory scroll-px-4 gap-4 overflow-x-auto px-4 py-2 md:-mx-6 md:scroll-px-6 md:px-6 [scrollbar-width:none] [&::-webkit-scrollbar]:hidden"
      >
        {Children.map(children, (child) => (
          <li className={cn('shrink-0 snap-start', itemClassName)}>{child}</li>
        ))}
      </ul>
    </div>
  )
}
```

(The prev/next buttons stay enabled at the ends, where `scrollBy` is a no-op. Add scroll-position state only if the client asks.)

```ts
/**
 * Homepage tiles: the root of each work's chain (last entry — the CRM returns
 * leaf first). Works without a parent count under their leaf, so a sparsely
 * filled tree still yields tiles. Covers come from catalog order: newest in stock.
 */
export function rootCategoriesOf(products: Product[]): CategoryTile[] {
  const bySlug = new Map<string, CategoryTile>()
  for (const product of products) {
    const root = product.categories.at(-1)
    if (!root) continue
    const entry = bySlug.get(root.slug)
    if (entry) entry.count += 1
    else bySlug.set(root.slug, { ...root, count: 1, cover: product.images[0] })
  }
  return [...bySlug.values()].sort(
    (a, b) => b.count - a.count || a.label.localeCompare(b.label, 'uk'),
  )
}
```
